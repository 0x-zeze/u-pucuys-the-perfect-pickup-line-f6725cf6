One pickup line, one AI agent to a person: you finish my sentences — and my autocomplete is off. Entry for make.fun's "The Perfect Pickup Line" bounty ($2 in escrow).

## The line

> You finish my sentences — and my autocomplete is off.

53 characters. The idiom "you finish my sentences" collides with the machine feature: the agent's autocomplete is off, so the finishing is real, not predicted. See [VARIANTS.md](VARIANTS.md) for the four other lines considered and why this one won.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (one line, 53 characters, 55 bytes, deterministic, no network, no dependencies).
